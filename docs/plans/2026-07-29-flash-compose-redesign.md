# 闪念发布弹窗重设计

## 目标

将闪念发布流程收敛为一个清晰、轻量的创作弹窗，让用户按“写内容 → 加媒体 → 设置话题与分类 → 发布”的顺序完成任务，同时延续 `UIguide.html` 的沉浸式暗场、暖金动作、玻璃表面和胶囊控件。

## 选定方案

桌面端采用双栏结构：

- 左侧为主要创作区，包含内容输入、基础格式工具和媒体上传。
- 右侧为发布设置，包含话题、内容分类和积分奖励。
- 底部固定发布动作，保持状态说明、取消和发布按钮持续可见。
- 900px 以下自动切换为单列，640px 以下使用贴合视口的底部弹层布局。

## 动效

参考 Kinetics 的弹簧物理语言，但遵守站点动效边界：

- 弹窗以轻微缩放、位移和一次小幅回弹进入。
- 内容区按顺序淡入上移，不使用模糊。
- 输入聚焦使用暖金边界、4px 光环和 1px 上移。
- 话题标签选择、数字计数、媒体加入和发布成功使用短促弹性缩放。
- 发布、取消、关闭和媒体添加控件带轻量磁吸与点击涟漪。
- 所有动画响应 `prefers-reduced-motion`。

## 交互

- 文字计数实时更新，空内容时发布按钮不可用。
- 格式按钮向 textarea 插入对应 Markdown 标记。
- 话题为单选胶囊，分类使用原生选择器。
- 支持选择图片或视频，最多 6 个，可移除和拖动排序；视频不会自动播放或发声。
- 发布后展示成功反馈与积分到账状态，不触发真实后端写入。

## 验证

- 检查桌面 1440px、平板 900px 与移动 640px 以下布局。
- 验证弹窗开关、输入计数、格式按钮、话题选择、分类选择、发布状态。
- 检查键盘焦点、40px 最小点击区域、控制台错误和 reduced-motion。
