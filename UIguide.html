DUOYUAN SHIGUANG · UI SYSTEM

沉浸式暗场
创作界面规范

以近黑暗场承载作品与模型，以暖金建立行动层级，以克制的玻璃表面、线型图标和编辑式排版形成多元拾光统一的创作社区体验。

01 内容先于容器

让作品、视频和模型信息成为主角，容器只承担层级与交互提示。

02 暗场而非纯黑

用近黑层级、低透明表面与局部光晕建立深度，不用厚重面板堆叠。

03 暖金只给关键动作

选中态、主行动、积分与核心数据使用暖金，其余内容保持中性。

04 轻量但可感知

反馈通过 1–2px 位移、边界增亮和短时缓动完成，不制造界面噪音。

Color

深色层级 + 四阶暖金体系

背景从 #05070B 起步，表面通过透明度和阴影抬升。主题金负责主动作，亮金和深金建立层级，香槟金仅用于邀请页；中性色统一使用 5% / 11% / 24% / 44% / 66% / 84% 六档透明度。

Responsive

当前以 1280+ 桌面为生产基线

现有十个页面与弹层主要服务桌面创作与浏览。下面把“当前生产规则”与“新增响应式页面的扩展规则”分开，避免把未来建议误认为现状。

Accessibility

暗色界面也要保持清楚和可操作

透明度是层级工具，不应让信息失去可读性。所有状态都需要颜色之外的第二种提示，键盘焦点必须可见。

文字对比

正文与背景达到 WCAG AA；低透明辅助文字不承载关键任务。

焦点可见

使用 2px 暖金外轮廓或等效光环，不依赖颜色轻微变化。

操作尺寸

图标按钮与点击目标至少 40 × 40px，胶囊高度至少 36px。

语义标签

纯图标按钮提供 aria-label；装饰图片使用空 alt。

状态冗余

成功、错误和选中态同时使用文字、图标、边界或位置提示。

减少动态

prefers-reduced-motion 下关闭位移、轮播自动切换和装饰动画。

Usage boundary

保持品牌，不制造“暗色后台”

多元拾光的核心不是把所有内容装进深色卡片，而是让创作内容在克制界面中被看见。以下边界用于新页面评审。

DO 用媒体与留白建立主次

让首屏只有一个明确焦点；用 16–48px 间距和渐隐遮罩组织信息。

DON'T 把每段内容都包进大面板

避免“大框套小框”、高对比描边和传统后台式模块堆叠。

DO 让暖金代表选择和行动

同一视区优先保留一个金色主动作，价格和积分可作为次级金色信息。

DON'T 同时使用多种高饱和强调色

酸橙与薄荷只服务特定语义，不与暖金争夺主行动层级。

DO 为内容类型选择专用卡片

作品、模型、教程和帖子使用不同信息结构，但共享圆角、边界和状态。

DON'T 复制一个万能卡片到所有页面

统一不等于相同；先保证任务结构，再复用视觉令牌和交互规则。
